ShiftNinja

PDF, Word & photo tools

How to use

  1. 1Start dragging any PDF, Word file or photo
  2. 2Press Shift – a wheel opens
  3. 3Drop it on a petal. The new file is saved next to the original

Tap Shift again (or scroll) for the Tools wheel: crop, compress, passport photos, merge…
